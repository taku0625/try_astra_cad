# 一体台座：形状版 7ccf8bb の確認済み印刷ファイル

- `fixture_integrated_7ccf8bb.stl`：印刷用治具1部品。6004三角形、単一の閉じたメッシュです。
- `fixture_integrated_7ccf8bb.step`：最終の印刷形状だけを、名前付きの単一ソリッドとして再書き出ししたSTEPです。
- `stl_import_preview.png`：このSTLの頂点から直接作成した確認画像です。CAD画面や描画キャッシュは使用していません。
- `import_verification.json`：寸法・パイプ穴・チェックサムの確認記録です。

Bambu Studioでは新しいプロジェクトに、上記STLまたはSTEPのどちらか1個を読み込んでください。移動・回転・拡縮前のサイズは **X=145、Y=100、Z=62 mm** です。後方にφ25.6 mmのパイプ穴と2本の長穴がある、下面の平らな一体台座です。

センサーと市販カラー・カーボンパイプは組立参考部品です。印刷用STL/STEPには治具だけが含まれます。

比較用の過去形状：パイプ穴追加前は86×100×62 mm、段付き取付座の版は145×100×70 mmです。

この配布セットはコミット7ccf8bbの形状を固定したものです。通常の `output/fixture.stl` と形状は同じで、STLは識別ヘッダーだけ変更しています。STEPは単一の名前付きオブジェクトとして再書き出しし、元データとの形状差がないことを検証しています。製品カラーの取付寸法とパイプ径は引き続き暫定です。

今回の確認ではFreeCADによるSTL/STEP再読込、境界寸法、単一部品、パイプ穴と台座の実形状、元STEPとの差分ゼロを検証しました。Bambu Studio 2.9.1.70の公式Linux版を取得・チェックサム検証しましたが、libwebkit2gtk-4.1.so.0とlibjavascriptcoregtk-4.1.so.0が環境にないため起動できず、Bambu Studio上での読み込み検証は未完了です。旧版が表示される原因はまだ特定できていません。
